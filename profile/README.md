# Seedlands

## Voxel sandbox game infra for agents.

**Seedlands** is building a living sword-and-magic open world that runs on its own terms. The world is not organized around the player: the player enters it, observes it, and leaves a trace within it.

We design for agents at the engine layer from the start. Agents should be able to develop and customize the world through clear systems, and genuinely experience the same world rather than merely operating an external control surface.

## Seedlands：面向 Agent 的体素沙盒游戏基础设施

**Seedlands** 正在构建一个会自主运行的剑与魔法开放世界。世界不围绕玩家运转；玩家进入其中、观察其中，并在其中留下自己的痕迹。

我们从引擎层开始支持 Agent。Agent 应能通过清晰的系统参与开发与定制，也应能真实地体验同一个世界，而不只是操作一个外部控制界面。

## What exists today / 当前进展

**Seedlands Web Sandbox** is the current playable product: an experimental browser voxel sandbox and the technical foundation for the wider project.

- Deterministic terrain, climate, biomes, rivers, lakes, trees, and chunk streaming.
- An authoritative world state, editable voxels, browser persistence, and optimized chunk meshes.
- A local single-player survival and exploration MVP with crafting, combat, water, a macro map, and a small deterministic ecology.
- A Web runtime built around explicit world, worker, physics, rendering, and persistence boundaries.

**Seedlands Web Sandbox** 是当前可直接游玩的产品：一个实验性的浏览器体素沙盒，也是更大 Seedlands 项目的技术基础。

- 已具备确定性地形、气候、生物群系、河湖、树木与 Chunk 流式加载。
- 已具备权威世界状态、可编辑体素、浏览器持久化与优化后的 Chunk 网格。
- 已具备本地单人生存探索 MVP，包括合成、战斗、水体、宏观地图与小型确定性生态。
- Web 运行时围绕清晰的世界、Worker、物理、渲染和持久化边界构建。

## The long view / 长期愿景

We are working toward a world shaped by unified natural rules, autonomous inhabitants, persistent historical consequences, and lives that can continue through reincarnation. Essence and magic, autonomous NPC societies, persistent history, longevity and reincarnation, and the six realms are directions for the full Seedlands vision—not features we claim are complete today.

我们的长期方向是：由统一自然规律、自主居民、持久历史后果和跨转生生命共同塑造的世界。源质与魔法、自主 NPC 社会、持久历史、长生与转生，以及六界内容，属于完整 Seedlands 的愿景，尚不应被表述为当前已交付能力。

## Build in the open / 开源共建

We welcome contributions that strengthen the sandbox and its foundations. Please start with the [contribution guide](https://github.com/seedlands-game/seedlands-web-sandbox/blob/main/CONTRIBUTING.md), search existing issues, and open an issue before proposing a large feature, public-contract change, persistence migration, world-generation change, or rendering-architecture change.

欢迎参与沙盒及其基础能力的共建。请先阅读[贡献指南](https://github.com/seedlands-game/seedlands-web-sandbox/blob/main/CONTRIBUTING.md)，检索已有 Issue；对大型功能、公开契约、存档迁移、世界生成或渲染架构变更，请先发起 Issue 讨论。
